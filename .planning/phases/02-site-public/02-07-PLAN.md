<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| anonymous browser -> POST /api/contact | Fully untrusted body: field contents, honeypot, submit-time origin, headers |
| /api/contact -> Resend | Outbound third party carrying visitor-supplied name, email and message |
| /api/contact -> Supabase | Anon-key insert under RLS |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-06 | Spoofing | contact form | mitigate | honeypot `societe` + 3000 ms minimum time-to-submit + 5-per-10-min IP rate limit, all evaluated before any send or insert (D-35) |
| T-02-07 | Tampering | request body | mitigate | Zod parse at the route entry, `profil` constrained to a four-value enum, unknown keys stripped |
| T-02-08 | Information disclosure | RESEND_API_KEY | mitigate | optional in `serverEnv`, strictly parsed at request time inside a `server-only` module, never logged, empty in `.env.example` (D-34) |
| T-02-09 | Information disclosure | stored contact messages | mitigate | no anon select policy on `app.contact_message`, and no GET/DELETE/export route exists (D-28, D-37) |
| T-02-10 | Denial of service | mail-relay abuse | mitigate | rate limit precedes the send; honeypot and time-gate reject before the transport is touched |
| T-02-11 | Repudiation | lost submission on transport failure | accept | the row is committed before the send and is not rolled back on a 502; a stored message with a failed notification is recoverable, a lost one is not |
| T-02-SC | Tampering | npm/pip/cargo installs | mitigate | this plan installs NO package — Resend is called over `fetch`, the rate limiter is a `Map`. If any install becomes necessary, stop and raise a blocking human legitimacy checkpoint before running the installer. |
</threat_model>
