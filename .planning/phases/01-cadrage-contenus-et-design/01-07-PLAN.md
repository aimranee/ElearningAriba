<objective>
Wave 2 of the locked wave shape (D-35), visual half: deliver **the pictograms**
of `CADR-04` and the shared presentational chrome the eleven maquettes render
inside.

Purpose: `CADR-04` names professional photography, SAP Ariba interface captures
and pictograms. D-06 rules that the quality bar is reachable **with no
photography at all** — the design reference loads five images and zero
photography, and all its richness is gradients, blurred blobs, a grain overlay
and a symbol sprite. So the photography and the captures are an **enhancement
that waits on the client's library**, and the pictograms ship now.

The header and footer are here because `PUB-12` (navigation in two clicks, a
complete footer) is Lot 2's *behaviour*, but eleven full-fidelity maquettes
without shared chrome look unfinished to the client at the validation gate. What
ships here is presentational only — links, labels and layout, no routing logic,
no active-state computation, no menu state persistence.

Output: one pictogram module, two layout components, and their mount in the root
layout.
</objective>

Each pictogram is a `function` declaration returning an inline `<svg>` that:
- has `viewBox="0 0 24 24"` and **no `width` or `height` attribute**, so the
  `size-*` utility from the icon contract governs it
- uses `fill="none"` with `stroke="currentColor"` (or `fill="currentColor"` where
  a solid mark reads better), so it inherits the surrounding text colour and can
  be tinted `text-primary` or `text-success` by the call site
- has `stroke-width`, `stroke-linecap="round"` and `stroke-linejoin="round"`
  consistent across the whole set — a set that mixes weights reads as clip-art
- carries `aria-hidden="true"` and `focusable="false"` by default, because a
  pictogram beside a label is decorative; accept and spread
  `React.ComponentProps<"svg">` so a call site can override `aria-hidden` and add
  a `<title>` when the icon carries meaning alone

Export every pictogram as a named export **and** export a
`pictograms` record mapping the exact `picto` string used in
`src/locales/fr/landing.json` to its component, typed as
`Record<string, React.ComponentType<React.ComponentProps<"svg">>>` — never
`any`. The registry is what lets a maquette render
`landing.pourQui.profils[n].picto` without a switch statement.

Also export a `PictogramName` type derived from the registry keys with
`keyof typeof pictograms`, so a maquette that references a missing name is a
**compile error** rather than a blank space.
