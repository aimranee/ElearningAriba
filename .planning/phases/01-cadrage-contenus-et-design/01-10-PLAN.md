<interfaces>
**The route template** — `src/app/page.tsx`: server component, `export default
function <PascalName>()`, synchronous, **not** `async`, **no `metadata` export
on the page**. The layout owns the chrome — plan 01-07 mounted `Header`,
`<main className="flex-1">` and `Footer` in `src/app/layout.tsx`, so a route
renders its content and nothing else. Typed routes: a page taking no params omits
props entirely; the type, if ever needed, is the generated `PageProps<"/route">`
global — never a hand-written interface.

**Available from earlier plans:**
- `@/components/sections/section` → `Section`, `SectionHeader` (plan 01-09)
- `@/components/ui/{button,card,badge,message,accordion,input,field,empty-state}`
- `@/components/icons/pictograms` → the `pictograms` registry, `PictogramName`
- `@/locales/fr/{programme,formation,a-propos,contact,common}.json`
- `@/lib/i18n/fr.ts` → `formatNumber`

**Field family API** (plan 01-06): `Field`, `FieldLabel`, `FieldControl`,
`FieldDescription`, `FieldError`. `FieldError` renders the shared `Message` with
`variant="error"` and `role="alert"`. The server-rejected state is the
`data-rejected="server"` attribute on `Field` — a named deliverable distinct from
client-side `aria-invalid`.

**Slugs (D-31):** these four routes are `/programme`, `/formation`, `/a-propos`,
`/contact`. Directory names must match exactly, accents and hyphens included —
`a-propos`, not `à-propos` and not `about`.
</interfaces>

**Hard prohibitions:**
- ⛔ **No form submission, no `action`, no `onSubmit`, no server action, no `fetch`, no contact-form backend, no spam protection.** `PUB-11` is Lot 2 (D-41). The contact form is a maquette of a form.
- ⛔ No page logic, no data fetching, no `async` page (D-41).
- ⛔ No per-route `metadata`, Open Graph, Twitter Card or structured data (D-41, Lot 5).
- ⛔ No French string literal in JSX (D-29). If a key is missing, **stop and report** — plan 01-03 owns the copy and adding a key here creates a conflict.
- ⛔ No hand-written price or unit string; numbers format through `formatNumber` (D-30).
- ⛔ « Apprenez à votre rythme » and « Accès 24/7 » stay struck (D-15).
- ⛔ In « format et modalités » content on `/formation`, formations live leads and *vidéos à venir* is never an included modality (D-14).
- ⛔ No raster asset, no photograph, no SAP Ariba capture, nothing under `public/` (D-06, D-21).
- ⛔ Do not modify any file under `src/components/`, `src/locales/`, `src/app/globals.css` or `src/app/layout.tsx` — other plans own them.
- ⛔ Do not run `npm install`. Do not `git push`, create a PR, or run `vercel` (D-38).
