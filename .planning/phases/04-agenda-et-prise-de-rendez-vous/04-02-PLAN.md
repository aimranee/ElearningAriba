<objective>
Bootstrap the agenda so it is never empty: one idempotent, environment-driven seed script that
promotes the trainer to `administrator`, seeds the two appointment types from the Lot 1-validated
`agenda.json`, opens a typical Monday-to-Friday week, and pre-fills the eleven French public
holidays closed. Then prove the read-time free-slot expansion behaves correctly at its boundaries.

Purpose: D-02 forbids a slot table and a generation job, so the only thing standing between an
empty agenda and a demonstrable one is the seed. D-22 exists so the CQO recette has material from
the very first run, and D-13's booking window and D-23's silent grey-out are behaviours no build
command can assert — they need SQL assertions against the applied function.

Output: `scripts/seed-agenda.mjs`, an `agenda:seed` npm script, a new `src/locales/fr/admin.json`,
and two SQL test files.
</objective>
