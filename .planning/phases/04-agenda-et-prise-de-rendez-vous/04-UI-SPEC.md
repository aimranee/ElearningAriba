## Spacing Scale

Inherited from `globals.css` (`--spacing: 0.25rem` → Tailwind's 4px step). Lot 4 declares no
new spacing token.

| Token | Value | Tailwind | Usage in Lot 4 |
|-------|-------|----------|-----------------|
| xs | 4px | `gap-1` | icon-to-label inside a slot badge, calendar cell inner padding |
| sm | 8px | `gap-2` | slot chips within a matin/après-midi group |
| md | 16px | `gap-4` / `px-4` | card internal padding, page gutter, admin table row padding |
| lg | 24px | `gap-6` / `py-6` | gap between calendar and slot-list panels, admin section gaps |
| xl | 32px | `gap-8` | admin sidenav to page content |
| 2xl | 48px | `gap-12` | title block to booking panel on `/agenda` |
| 3xl | 64px | `py-16` | page top/bottom padding on public surfaces (not on `/admin` — see below) |

**Exceptions:**
- **Touch targets: 44×44px minimum** on every slot chip, calendar day cell and admin action
  icon-button (mobile-first constraint from the experience contract) — same `h-11` call-site
  override idiom Lot 3 used at `header.tsx:100` and its own primary/destructive buttons. A call-
  site class, not a component edit.
- **Form inputs: 16px minimum font-size** on every booking-flow and admin text input — below
  16px, iOS zooms on focus and breaks the flow. `field.tsx`'s `input.tsx` already sets body-scale
  text (`text-base`/16px) by default; this phase must not shrink it at any call site.
- **`/admin` does not inherit the public `py-16` page rhythm.** A working-tool shell uses tighter
  vertical rhythm — `py-6`/`py-8` at the page level, consistent with `data-density="compact"`.
  This is a phase-specific exception, not a global scale change.
- **No horizontal scroll, ever** — the admin reservation table degrades to stacked cards below
  a defined breakpoint rather than scrolling sideways; the calendar grid uses `grid-cols-7` with
  no min-width escape hatch.

**Two new `Intl` formatters are required** (added to `src/lib/i18n/fr.ts`, never as a hand-

|---|---|---|

The **existing** `timeFormatter` (`14:30`, CLDR short) stays correct and unchanged for **dense
slot chips** in the grid — the two registers coexist by design (brief, "Heures — deux
registres"), they are not a bug to reconcile.

## Color

Inherited `:root` palette (`--violet` `#635BFF`). Lot 4 declares no new colour.

**Explicit rule (brief, "Positionnement chromatique"): never derive toward institutional blue.**
Doctolib owns blue in the French public's mind; violet/indigo is this product's differentiator.
A "serious, administrative" instinct on the admin shell must not reach for `--blue` (`#3B82F6`)
— it stays on the existing violet/ink palette.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--paper` `#FCFCFF` (`--background`) | page background, both public and `/admin` |
| Secondary (30%) | `#FFFFFF` (`--card`) + `--lav2` `#F6F5FF` (`--muted`) | every `Card`, admin sidenav band, greyed-out ("Indisponible") calendar cells |
| Accent (10%) | `--violet` `#635BFF` (`--primary`, `--ring`) | see reserved list below |
| Destructive | `#EF4444` (`--destructive`) | see reserved list below |
| Success | `--mint` `#1FC79B` (`--success`, `--success-muted` `#E6FAF3`) | see reserved list below |

**Accent `#635BFF` reserved for, and nothing else:**
1. The single primary action per screen: the selected date's ring/fill in the calendar, the
   chosen slot chip's fill, the screen-3 "Valider ma réservation" button, the admin "Enregistrer
   les horaires" / "Exporter" primary actions.
2. The focus ring (`--ring`) on every focusable element — calendar cells, slot chips, form
   controls, table row actions.
3. Inline text links (e.g. "Voir le programme" cross-link from the confirmation surface, if any).
4. `Badge variant="default"` for the currently-selected slot and for an admin "confirmée" status
   chip.

**Never on:** the day-off/greyed calendar cells (they read `--muted`, not accent — greying out
is a neutral state per D-23, not a call to action), the admin sidenav's resting items (`ghost`
until active), the legend swatches for "Passé"/"Indisponible", any decorative calendar chrome.

**Destructive `#EF4444` reserved for:** the admin "Annuler ce rendez-vous" / "Bloquer cette
plage" confirm buttons (tinted `destructive/10`, never a solid red block — same rule Lot 3 set),
`FieldError` text on admin forms, the slot-taken and second-discovery-call rejection `Message
variant="error"`.

**Success `#1FC79B` reserved for:** the booking-confirmed surface (screen 4) and its "Réservation
confirmée" `Badge`/`Message`, and an admin "confirmée" status where a colour-coded state (not
just text) is useful in the reservation table.

**D-23 grey-out is `--muted`, not `--destructive`.** "Indisponible" is not an error state — a
red-tinted unavailable slot would misread as a system failure. Every non-bookable cell (past,
booked, blocked, holiday) renders identically in `--muted`/`text-muted-foreground`, per D-23's
"the visitor only ever sees Indisponible."

## French typography and culture — verifiable on the rendered output

- **Sentence case only** — "Prendre rendez-vous", never "Prendre Rendez-Vous".
- **French guillemets « … »** with a non-breaking space inside, and a **curly apostrophe** ’.
- **Non-breaking space before `:`**, thin non-breaking space before `;`/`!`/`?`.
- **Non-breaking space before `€` and `%`** — `90 €`, never `90€`. Enforced by
  `currencyFormatter` (already exists) — never a hand-written `€`.
- **Accented capitals**: `É`, `À`, `Ç`.
- **Vouvoiement**, consistent with `agenda.json`/`reservation.json`/`espace.json` already shipped.
- **Prose hours** as `14 h 30` (new formatter, see Typography), **dense chips** as `14:30`
  (existing `timeFormatter`) — both correct, in their own context, never interchanged.
- **Dates carry the weekday** — `mardi 8 septembre` (new formatter, see Typography), never a
  bare `dateFormatter` output on an agenda surface.

## Acceptance criteria — applied outcomes

1. `git diff` for the whole phase touches **zero lines** in `src/app/globals.css` and the nine
   inherited `src/components/ui/*.tsx` files.
2. The public legend renders exactly **Libre / Indisponible / Passé** — no "Réservé"/"Bloqué"
   string reaches a visitor-facing route; both survive only inside `/admin`.
3. `agenda.typesRendezVous` prices/labels (0 €, 90 €) are byte-identical to today's
   `agenda.json` — no Lot 4 diff touches them.
4. Every price on a Lot 4 surface renders through `currencyFormatter`; every prose hour renders
   through the new hour-of-day formatter (`14 h 30`, never `14:30` in prose); every prose date on
   an agenda surface carries its weekday.
5. Booking is exactly **3 screens + 1 success surface** — no route or component introduces a
   fourth step before commit.
6. Screen 1 and 2 render and are usable **without an authenticated session**; the session is
   requested only at screen 3, and the previously chosen slot survives that detour (decision 28).
7. A chosen slot carries a visible 15-minute hold with explicit countdown copy; a lapsed hold
   returns the learner to slot selection with an explicit message, not a silent failure.
8. `/admin/*` is unreachable without `profil.role = 'administrator'` — a redirect happens before
   any markup renders, mirroring `/espace*`'s existing behaviour.
9. `/admin` surfaces render with `data-density="compact"` at their root and inherit the existing
   compact variants already present in `button`/`card`/`field`/`badge` — no new density system is
   authored.
10. No component in this phase reaches for `--blue` (`#3B82F6`) as a primary or accent colour.
