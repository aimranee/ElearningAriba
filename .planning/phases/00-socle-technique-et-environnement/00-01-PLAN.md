<objective>
Stand up the Next.js (React, TypeScript) application that every following phase
builds on: scaffolded with `create-next-app`, App Router, server-rendered,
sources under `src/`, `@/*` alias, French and `Europe/Paris` as the defaults, and
the Tailwind v4 + shadcn/ui styling toolchain installed and compiling.

Purpose: SOCLE-01. Without a running application there is nothing to configure
environments for, nothing to deploy, and nothing for a CI gate to check.

Output: A repository that installs and builds from a clean checkout, serves a
French-language document, and carries a styling toolchain whose visual values are
untouched library defaults reserved for the Lot 1 design system.

**This plan makes no design decision.** No palette, typeface, spacing scale or
component design is chosen — those are Lot 1 and are validated by the client.
Whatever colour or font values `shadcn init` writes are library defaults and are
labelled in the stylesheet as placeholders.
</objective>
