## Decisions Made

- The session-aware server client (`src/lib/supabase/server.ts`) reads the anon key, not the service-role key, from the server environment. The cookie-based `createServerClient` pattern is designed to respect row-level security for the calling user; a service-role/admin client that bypasses RLS is a distinct concern with no consumer yet in this plan (no admin surface exists before Lot 10). `serverEnv` still exposes `SUPABASE_SERVICE_ROLE_KEY` for whichever later lot needs it.
