# Quick Task 260831-n81: Fix hero assembly card mobile overflow Summary

**Assembly card's internal grid switches to single-column below 640px (`min-w-0` chain: Reveal wrapper → pills column → violet card), hand-authored SVG connectors hidden below the same breakpoint — fixes the measured 375px/382px overflow without touching the ≥640px layout.**

## Performance

- **Duration:** ~15 min
- **Tasks:** 2 completed

## Accomplishments

- Root-caused 375px overflow: `grid-cols-[.92fr_1.08fr]` with no breakpoint and no `min-width:0` anywhere in the chain, so grid items defaulted to `min-width:auto` and the card's 382px content width leaked past the viewport.
- Internal grid now `grid-cols-1 sm:grid-cols-[.92fr_1.08fr]` — stacks pills-then-violet-card below 640px (DOM order already correct, no reordering utility added), unchanged at and above 640px.
- Added `min-w-0` on the Reveal wrapper div, the pills column div, and the violet card div — all three are grid items that previously had nothing stopping them from forcing their track wider than available space.
- Connectors SVG hidden below 640px (`hidden sm:block`) since its hand-written bezier paths are anchored only to the side-by-side layout; no second path set authored.
