<objective>
Fix a measured 375px overflow on the hero assembly card. Root cause: the
card's internal grid is fixed to two columns
(`grid-cols-[.92fr_1.08fr]`) with no breakpoint and no `min-width:0`, so
grid items default to `min-width:auto` and the card cannot shrink below its
382px content width — that width leaks onto the hero column and the section's
`overflow-hidden` masks the resulting clip instead of fixing it. Below 640px
the card must stack to one column (pills first, then the violet result card —
DOM order already matches) and shrink to fit; the hand-authored SVG
connectors, drawn only for the side-by-side layout, must be hidden below
640px. Desktop (≥640px) stays byte-identical.
</objective>
