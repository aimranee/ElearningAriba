Exactly one wrapper is expanded at a time, driven by `isOpen`.

Structure per wrapper:
- Outer element: `className="grid overflow-hidden transition-[grid-template-rows] duration-[var(--duration-base)] ease-[var(--ease-brand)]"`, with `style={{ gridTemplateRows: expanded ? "1fr" : "0fr" }}` where `expanded` is `!isOpen` for the description wrapper and `isOpen` for the preuve wrapper.
- Inner element: a single direct grid child (`<div className="min-h-0">` wrapping the existing `<p>` description or the existing preuve `<div>` content) so the row can collapse to zero height without clipping mid-line.
- Visibility and a11y on the outer element: `aria-hidden={!expanded}`, and inline `style` merges the grid-template-rows transition with a delayed visibility transition so content is only hidden from assistive tech and tab order after the collapse animation finishes: `style={{ gridTemplateRows: expanded ? "1fr" : "0fr", visibility: expanded ? "visible" : "hidden", transition: "grid-template-rows var(--duration-base) var(--ease-brand), visibility 0s linear var(--duration-base)" }}`. Drop the Tailwind `transition-[grid-template-rows]` class in favor of this single inline `transition` shorthand (keep `overflow-hidden` and `grid` as Tailwind classes; only `gridTemplateRows`/`visibility`/`transition` move to inline `style`).

Description wrapper: `expanded = !isOpen`, inner content = the existing description `<p>` (drop its old `invisible`/`visible`/`col-start-1 row-start-1` classes — keep only its typography classes).

Preuve wrapper: `expanded = isOpen`, inner content = the existing preuve `<div>` (the `<p>{item.preuveTexte}</p>` plus the conditional `<Link>`) with its old overlay classes dropped the same way. Keep the `<Link>` outside the `<button>`, unchanged otherwise.

Keep the `<button>` and its `aria-expanded`/`aria-controls`/`onClick` exactly as-is. Do not touch the icon span, Card variant, or any color/contrast classes. Do not introduce any duration or easing value other than `var(--duration-base)` and `var(--ease-brand)`.
