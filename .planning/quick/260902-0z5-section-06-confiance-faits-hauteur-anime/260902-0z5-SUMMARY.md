# Quick Task 260902-0z5: Confiance faits — animated height Summary

Lifted D-64's zero-shift constraint on the Confiance section's fact cards. Replaced the fixed-height overlaid description/preuve swap with two sequential `grid-template-rows: 0fr → 1fr` wrappers, each individually height-animated, so collapsed height equals the description's natural height instead of the taller of the two blocks.

## What changed

- `.planning/phases/02-site-public/02-CONTEXT.md`: added **D-65** immediately after D-64, recording the founder decision to lift the zero-shift rule and the measured cost (90px/card, tripled on mobile, 1567px → 1683px section growth).
- `src/components/motion/confiance-faits.tsx`: replaced the single `<div className="mt-2 grid">` overlay (description/preuve stacked via `col-start-1 row-start-1` + `invisible`/`visible`) with two sibling wrappers inside `#{preuveId}`:
  - Description wrapper: `expanded = !isOpen`
  - Preuve wrapper: `expanded = isOpen`
  - Each wrapper: `className="grid overflow-hidden"`, inline `style` drives `gridTemplateRows: expanded ? "1fr" : "0fr"`, `visibility`, and a combined `transition` shorthand (`grid-template-rows var(--duration-base) var(--ease-brand), visibility 0s linear var(--duration-base)`).
  - Each wrapper's single grid child is a `<div className="min-h-0">` holding the original content, preventing mid-line clipping during collapse.
  - `aria-hidden={!expanded}` on each wrapper preserved for a11y.
- `<button>` (`aria-expanded`/`aria-controls`/`onClick`), icon span, Card variant, and the preuve `<Link>` (still outside the `<button>`) are unchanged.
